# 💊 MediGuide

**MediGuide** is an AI-powered, intelligent medicine educational platform. It provides detailed, easy-to-understand information about any medication, including its generic formulation, uses, side effects, and safe dosage.

## 🚀 Features
- **Advanced Drug Recognition**: Integrated with the National Library of Medicine (NLM) RxNorm API to auto-correct typos and resolve Indian/International brand names to generic formulations.
- **Google-Like Voice Search**: Fast, responsive voice search that automatically submits.
- **Smart Camera/OCR Scan**: Scan physical medicine boxes to instantly fetch details.
- **Common Terms Translation**: Automatically translates complex FDA medical jargon into simple, digestible terms like "Pain Relief" and "Reduces Stomach Acid".
- **Multilingual Support**: Built-in Google Translate integration.

## 🛠 Tech Stack
- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: Tailwind CSS
- **Data Sources**: OpenFDA API & RxNorm API
- **OCR Engine**: Tesseract.js
- **Icons**: Lucide React

## 💻 Running Locally

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
